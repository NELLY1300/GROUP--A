# Student Attendance Management System

This is a simple Java console-based application for managing student attendance. It allows users to register students, mark attendance, view individual records, and generate overall attendance reports.

## 📌 Features

- Register students with name and ID
- Mark attendance as Present (P) or Absent (A)
- View individual student attendance
- Generate attendance percentage report for all students
- Menu-driven interface with clear options

## 🧰 Technologies Used

- Java (Core)
- ArrayList for dynamic data storage
- Modular programming with functions for each operation

## 🧑‍💻 How to Run

1. Download or clone the project files.
2. Open the project in your Java IDE (IntelliJ, Eclipse, NetBeans, etc.) or any code editor.
3. Compile the program:
    ```bash
    javac AttendanceSystem.java
    ```
4. Run the program:
    ```bash
    java AttendanceSystem
    ```

## 🧭 Menu Example

```
--- Student Attendance Management System ---
1. Register Student
2. Mark Attendance
3. View Attendance
4. Generate Report
5. Exit
```

## 🧪 Sample Functionalities

- Add a student using option 1.
- Use option 2 to mark Present (P) or Absent (A).
- View a student’s attendance with option 3 by providing their ID.
- Get an attendance report using option 4.
